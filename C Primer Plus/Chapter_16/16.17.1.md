# 1.下面的几组代码由一个或多个宏组成，其后是使用宏的源代码。在每种情况下代码的结果是什么？这些代码是否是有效代码？（假设其中的变量已声明）
```
a.
#define FPM 5280 /*每英里的英尺数*/
dist = FPM * miles;


b.
#define FEET 4
#define POD FEET + FEET
plort = FEET * POD;


c.
#define SIX = 6;
nex = SIX;


d.
#define NEW(X) X + 5
y = NEW(y);
berg = NEW(berg) * lob;
est = NEW(berg) / NEW(y);
nilp = lob * NEW(-berg);


```


## 解答：


- a.有效，正常文本替换。

- b.有效，但写法不规范，应改为`#define POD (FEET + FEET)`。

- c.无效，展开后为nex == 6，这不是对nex赋值。

- d.有效，但是由于宏没有加括号，展开后按照运算顺序不能达到预期效果。
