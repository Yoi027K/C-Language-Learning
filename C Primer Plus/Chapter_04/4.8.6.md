# 编写一个程序，先提示用户输入名，然后提示用户输入姓。在一行打印用户输入的名和姓，下一行分别打印名和姓的字母数。字母数要与相应名和姓的结尾对齐。


## 解答：


```c
#include <stdio.h>
#include <string.h>

int main()
{
    int x, y;
    char n1[20], n2[20];

    printf("Please enter your first name: ");
    scanf("%19s", n1);
    printf("Please enter your last name: ");
    scanf("%19s", n2);
    x = strlen(n1);
    y = strlen(n2);
    printf("%s %s\n", n1, n2);
    printf("%*d %*d\n", x, x, y, y);
    printf("%s %s\n", n1, n2);
    printf("%-*d %-*d\n", x, x, y, y);

    return 0;
}
```
