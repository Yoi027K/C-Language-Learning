# 11.编写并测试Fibonacci()函数，该函数用循环代替递归计算斐波那契数。


## 解答：


```c
#include <stdio.h>

long long Fibonacci(int n)
{
    if(n==1 || n==2)   return 1;
    long long a = 1;
    long long b = 1;
    long long c;
    int cnt = 2;
    while(cnt!=n){
        c = a + b;
        a = b;
        b = c;
        cnt++;
    }
    return c;
}

int main()
{
    printf("%lld",Fibonacci(10));
    return 0;
}
```
