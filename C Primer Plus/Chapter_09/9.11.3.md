# 3.编写一个函数，接受3个参数：一个字符和两个整数。字符参数是待打印的字符，第1个整数指定一行中打印字符的次数，第2个整数指定打印指定字符的行数。编写一个调用该函数的程序。


## 解答：


```c
#include <stdio.h>

void f(char c,int cnt,int row)
{
    for(int i=0;i<row;i++){
        for(int j=0;j<cnt;j++){
            printf("%c",c);
        }
        printf("\n");
    }
}

int main()
{
    f('$',5,5);
    return 0;
}
```
