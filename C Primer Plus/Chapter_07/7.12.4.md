# 4.使用if else语句编写一个程序读取输入，读到#停止。用感叹号替换句号，用两个感叹号替换原来的感叹号，最后报告进行了多少次替换。


## 解答：


```c
#include <stdio.h>

int main()
{
    int cnt = 0;
    int c;
    while(((c=getchar())!='#')){
        if(c == '.'){
            putchar('!');
            cnt++;
        }
        else if(c == '!'){
            putchar('!');
            putchar('!');
            cnt++;
        }
        else{
            putchar(c);
        }
    }
    printf("%d",cnt);
    return 0;
}
```
