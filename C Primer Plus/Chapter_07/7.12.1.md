# 1.编写一个程序读取输入，读到#字符停止，然后报告读取的空格数、换行符数和所有其他字符的数量。


## 解答：


```c
#include <stdio.h>

int cnt,space,newline;
int main()
{
    int c;
    while((c=getchar())!='#'){
        cnt++;
        if(c = ' '){
            space++;
        }
        else if(c = '\n'){
            newline++;
        }
    }
    printf("space = %d\nnewline = %d\nother = %d",space,newline,cnt-(space+newline));
    return 0;
}
```
