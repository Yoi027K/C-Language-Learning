# 6.编写程序读取输入，读到#停止，报告ei出现的次数。


## 解答：


```c
#include <stdio.h>

int main()
{
    char pre = '#';
    char now = '#';
    int cnt = 0;
    while((now = getchar())!='#'){
        if(pre == 'e' && now == 'i'){
            cnt++;
        }
        pre = now;
    }
    printf("%d",cnt);
    return 0;
}
```
