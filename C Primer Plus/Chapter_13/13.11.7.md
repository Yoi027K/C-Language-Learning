# 7.编写一个程序打开两个文件。可以使用命令行参数或提示用户输入文件名。


## 解答：


```c
#include <stdio.h>
#include <ctype.h>

int main()
{
    FILE *p1,*p2;
    int ch;
    char name1[50];
    char name2[50];

    printf("Enter the first file name: ");
    scanf("%s",name1);
    printf("Enter the second file name: ");
    scanf("%s",name2);

    p1 = fopen(name1,"r");
    while((ch = fgetc(p1)) != EOF){
        putchar(ch);
    }
    p2 = fopen(name2,"r");

    fclose(p1);
    fclose(p2);
}
```
