# 5.编写一个程序，提示用户输入大写字母。使用嵌套循环以金字塔型的格式打印字母：


## 解答：


```c
#include <stdio.h>

int main()
{
    char c;

    printf("Please enter a letter: ");
    scanf("%c", &c);

    int length = c - 'A';
    for (int i = 0; i <= length; i++)
    {
        char t = 'A' - 1;
        for (int j = 0; j < length - i; j++)
        {
            printf(" ");
        }
        for (int j = 0; j <= i; j++)
        {
            printf("%c", ++t);
        }
        for (int j = 0; j < i; j++)
        {
            printf("%c", --t);
        }
        printf("\n");
    }

    return 0;
}
```
