# 3.编写一个函数，返回储存在int类型数组中的最大值，并在一个简单的程序中测试该函数。


## 解答:


```c
#include <stdio.h>
#include <limits.h>

int max(int a[],int n)
{
    int max = INT_MIN;
    for(int i=0;i<n;i++){
        if(a[i]>max){
            max = a[i];
        }
    }
    return max;
}

int main()
{
    int a[10] = {1,4,7,8,55,22,11,0,47,52};
    int size = sizeof(a)/sizeof(a[0]);
    printf("%d",max(a,size));
    return 0;
}
```
