# 1.编写一个函数，把二进制字符串转换为一个数值。例如，有下面的语句：char * pbin = "01001001";那么把pbin作为参数传递给该函数后，它应该返回一个int类型的值25。


## 解答：


```c
#include <stdio.h>
#include <string.h>

int trans(char* s)
{
    int ans = 0;
    int flag = 1;
    int len = strlen(s);
    for(int i=len-1;i>=0;i--){
        if(s[i]=='1'){
            ans += flag;
        }
        flag *= 2;
    }
    return ans;
}

int main()
{
    char * pbin = "01001001";
    printf("%d",trans(pbin));
    return 0;
}
```
