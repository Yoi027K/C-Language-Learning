# 5.编写一个程序，生成100个1～10范围内的随机数，并以降序排列（可以把第11章的排序算法稍加改动，便可用于整数排序，这里仅对整数排序）。


## 解答：


```c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>
#define n 100

int a[105];

int main()
{
    srand((unsigned)time(NULL));

    for(int i=0;i<n;i++){
        a[i] = rand() % 11;
    }

    for(int i=0;i<n;i++){
        for(int j=0;j<n-i-1;j++){
            if(a[j]<a[j+1]){
                int temp = a[j+1];
                a[j+1] = a[j];
                a[j] = temp;
            }
        }
    }

    for(int i=0;i<n;i++){
        printf("%d\n",a[i]);
    }

    return 0;
}
```
