# 1323. 6 和 9 组成的最大数字

给你一个仅由数字 6 和 9 组成的正整数 `num`。

你最多只能翻转一位数字，将 6 变成 9，或者把 9 变成 6 。

请返回你可以得到的最大数字。

## 反转，再处理数字

```cpp
class Solution {
public:
    int maximum69Number (int num) {
        int n = num;
        int ans = 0;
        int flag = 1;
        int rever = 0;
        while(n>0){
            int digit = n % 10;
            rever = rever*10 + digit;
            n /= 10;
        }
        while(rever>0){
            int digit = rever % 10;
            if(digit == 6 && flag){
                digit = 9;
                flag = 0;
            }
            ans = ans*10 + digit;
            rever /= 10;
        }
        return ans;
    }
};
```

## 字符串 + find

```cpp
class Solution {
public:
    int maximum69Number (int num) {
        string s = to_string(num);
        int p = s.find('6');
        if(p!=string::npos){
            s[p] = '9';
        }
        else{
            return num;
        }
        return stoi(s);
    }
};
```
