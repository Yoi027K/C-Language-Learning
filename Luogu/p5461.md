**题目描述**
现有 $2^n \times 2^n$ $(n \le 10)$ 名作弊者站成一个正方形方阵等候K的发落。K决定赦免一些作弊者。他将正方形矩阵均分为 4 个更小的正方形矩阵，每个更小的矩阵的边长是原矩阵的一半。其中左上角那一个矩阵的所有作弊者都将得到赦免，剩下 3 个小矩阵中，每一个矩阵继续分为 4 个更小的矩阵，然后通过同样的方式赦免作弊者……直到矩阵无法再分下去为止。所有没有被赦免的作弊者都将被处以棕名处罚。

给出 n，请输出每名作弊者的命运，其中 0 代表被赦免，1 代表不被赦免。

**输入格式**
一个整数 n。

**输出格式**
$2^n \times 2^n$ 的 01 矩阵，代表每个人是否被赦免。数字之间有一个空格。


**My answer :**

```c
#include <stdio.h>
#include <string.h>

int a[1024][1024];

void f(int a[1024][1024],int x,int y,int len)
{
    if(len==1)   return;

    int half = len / 2;

    for(int i=x;i<x+half;i++){
        for(int j=y;j<y+half;j++){
            a[i][j] = 0;
        }
    }

    f(a,x+half,y,half);
    f(a,x,y+half,half);
    f(a,x+half,y+half,half);
}

int main()
{
    for(int i=0;i<1024;i++){
        for(int j=0;j<1024;j++){
            a[i][j] = 1;
        }
    }

    int n;
    scanf("%d",&n);
    int size = 1<<n;
    f(a,0,0,size);

    for(int i=0;i<size;i++){
        for(int j=0;j<size;j++){
            printf("%d ",a[i][j]);
        }
        printf("\n");
    }

    return 0;
}
```
