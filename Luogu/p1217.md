**题目描述**<br>
因为 151 既是一个质数又是一个回文数（从左到右和从右到左是看一样的），所以 151 是回文质数。

写一个程序来找出范围 [a,b] $5≤a<b≤100,000,000$（一亿）间的所有回文质数。

**输入格式**<br>
第一行输入两个正整数 a 和 b。

**输出格式**<br>
输出一个回文质数的列表，一行一个。

**My answer:**<br>

```c
#include <stdio.h>

int isPrime(int n)
{
    if(n<2)   return 0;
    if(n%2==0)   return 0;
    for(int i=2;i*i<=n;i++){
        if(n%i==0){
            return 0;
        }
    }
    return 1;
}

int rever(int n)
{
    int rev = 0;
    int n1 = n;
    while(n>0){
        int digit = n%10;
        rev = rev*10+digit;
        n/=10;
    }
    if(rev == n1)   return 1;
    else return 0;
}

int main()
{
    int l,r;
    int kkk;
    scanf("%d %d",&l,&r);

    for(int i=l;i<=r;i++){
        if(isPrime(i)){
            if(rever(i))
            printf("%d\n",i);
        }
    }

    return 0;
}
```
